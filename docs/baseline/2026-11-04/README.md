## 측정의 범위

이 자료는 현재 유한 월드의 기준선이다. CPU 시간·관리 할당은 프레임 FPS, P95/P99, GPU 메모리나 전체 상주 메모리가 아니다. 스트레스 할당은 살아남은 메모리 크기가 아니며 새 메시 비교를 포함한다. 장시간 게임·무한 스트리밍과 향후 시스템 성능은 아직 측정하지 않았다. 다른 런타임/하드웨어의 과거 수치와 직접 속도 개선율을 계산하지 않는다. 원격 Windows/Linux CI 재실행과 배포본 실행은 이 기준선의 범위 밖이다.
